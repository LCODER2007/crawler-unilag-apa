# URAAS — African Research Archival & Analytics System

**University Research Analytics and Archiving System** — Built for the Africa PID Alliance.

Discovers Special Collections papers from 13 web sources (OpenAlex, AJOL, DOAJ, Crossref, Semantic Scholar, etc.), classifies them using AI, and deposits to DSpace IR via an email approval gate. Mints ARK persistent identifiers for every item.
